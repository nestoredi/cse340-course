Why do you think EJS makes a distinction between `<%-` and `<%=`? What security or output issues might occur if we accidentally used `<%-` to output raw user input like `<%- user.displayName %>`?


[NÉSTOR]

[MENTOR]
You are right on the mark about security! 

To elaborate on that exact detail: the equals sign (`<%=`) automatically escapes HTML special characters (turning characters like `<` or `>` into safe entity codes like `&lt;` or `&gt;`). This prevents a very common web vulnerability called Cross-Site Scripting (XSS), where a malicious user might try to input dynamic HTML or `<script>` tags into their username. On the other hand, the hyphen (`<%-`) renders raw, unescaped HTML—which is necessary when including external template files like partials!
